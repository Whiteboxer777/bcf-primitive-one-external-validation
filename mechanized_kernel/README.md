# mechanized_kernel

This directory contains the mechanized-kernel preparation surface for BCF Primitive One.

It is intentionally narrower than the whole primitive family. It covers only the smallest theorem kernel judged highest-value before final RC regeneration:

- K1 verdict universe / totality core
- K2 verification necessity core
- K3 fail-closed core
- K4 admission biconditional core
- K5 no-bypass core
- K6 canonicalization determinism/idempotence core (subset)

The checker is not a theorem prover. It is a mechanically executed finite-state theorem kernel over an explicit abstract semantics model plus canonicalization subset checks over concrete corpus fixtures.
