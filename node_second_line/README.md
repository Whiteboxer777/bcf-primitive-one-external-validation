# BCF Primitive One Node Second Line

This package is an out-of-family second implementation line in Node.js.

It is not a wrapper around the Python runtime. It reimplements the following primitive-boundary surfaces using Node.js built-ins only:

- canonicalization and digest derivation
- bundle verification
- runtime request evaluation
- refusal construction
- permit construction
- replay verdict surface

Its role is parity testing against the primary Python line, the independent Python second line, and the externalized Python line.
