# `SPEC/OBJECT_CANONICALIZATION_IMPOSSIBILITY_SATURATION.md`

## 0. Status

This document defines a scoped executable-witness saturation pass over three previously weaker law regions of BCF Primitive One:

- object-model family execution discipline
- canonicalization family breadth
- impossibility-family witness depth

## 1. Purpose

The purpose of this pass is to convert these three families from merely partial theorem-ledger regions into stronger executable witnesses backed by dedicated corpus material, adversarial probes, gate reports, adequacy rows, and theorem-discharge truth sync.

## 2. Exact scope

This pass is scoped to currently implemented object families and currently implemented canonicalization surfaces. It is narrower than theorem-prover closure and narrower than every possible future object-family extension.

## 3. Saturated object-model regions

The following are saturated by executable witness in this pass:

- verification-result structural validity
- permit structural validity
- refusal structural validity
- witness-certificate structural validity for verification, permit, refusal, replay-allow, and replay-refusal outputs
- schema-negative object mutations proving required-field discipline and structural rejection of malformed objects

## 4. Saturated canonicalization regions

The following are saturated by executable witness in this pass:

- request equality / distinctness
- action equality / distinctness
- generic object equality / distinctness
- idempotence across these canonicalization surfaces

## 5. Saturated impossibility regions

The following are saturated by executable witness in this pass:

- no allow without verified boundary
- no permit on refusal path
- no third final verdict beyond `{ALLOW, REFUSAL}`
- no bypass positive authority
- invalid action descriptor does not yield allow

## 6. Truth boundary

This pass strengthens executable saturation for these three law regions but does not claim theorem-prover-grade closure of the entire primitive family.
